# 客户价值主张
> 被充分还原的需求

商业模式其中的两个重要维度：
- 第一，我到底能为客户提供什么？
卓越的企业之所以卓越，就在于它们具有对客户需求的还原能力，我们可以称之为“需求考古学”。考古学的特点是:找到埋藏着文物的地方，并将它发掘出来，通过一件文物还原一个时代。

- 第二，我凭什么来实现客户价值？
清清楚楚的创意往往是无视自身资源与能力的构想，它可能确实包含着商机，但也很可能是别人(具有与之相匹配的资源和能力的人)的商机。商业模式通常分为深思熟虑型和应急型两种，但实际起作用的商业模式往往都是二者的混合，是在不断的应急之中和之后深思熟虑的产物。

电影院提供的（容易化掉的）冰淇淋、凉了就不好吃的爆米花。
客户价值主张如果没有相应的资源(客户资源、产品渠道)和能力作为支撑，就难以形成商业模式，尤其是难以实现可持续、可赢利的收入流。


戴尔的客户价值主张很清楚：向那些无力或不愿意购买高价格、无个性化配置的“正牌”电脑的人提供电脑。

“商业模式是一种包含了一系列**要素及其关系**的概念性工具，用以阐明**某个特定实体**的商业逻辑。它描述了公司所能**为客户提供的价值**以及**公司的内部结构、合作伙伴网络和关系资本**等用以实现(创造、营销和交付)这一价值并产生可持续、可赢利性收入的要素。”

# 构建商业模式的九要素


| -    | 要素          | 描述             |
| :------ | :------------- | :------------------- |
| 产品 | 价值主张（Value Proposition） | 公司通过其产品和服务所能向消费者提供的价值。价值主张确认了公司对消费者的实用意义。|
| 顾客界面 | 消费目标群体（Target Customer Segments） | 公司所瞄准的消费者群体。这些群体具有消费者目标群体(Target某些共性，从而使公司能够(针对这些共性)创造价值。定义消费者群体的过程也Customer Segments)被称为市场细分。|
| 顾客界面 | 分销渠道（Distribution Channels） | 公司用来接触消费者的各种途径，它阐述了公司如何开拓市场。它涉及公司的市场和分销策略。|
| 顾客界面 | 客户关系（Customer Relationships） | 同其消费者之间所建立的联系 |
| 管理架构 | 价值配置（Value Configuration） | 资源和活动的配置 |
| 管理架构 | 核心能力（Core Capabilities） | 公司执行其商业模式所需要的能力和资格 |
| 管理架构 | 合作伙伴网络（Partner Network） | 公司同其他公司之间为有效地提供价值并实现其商业化而形成的合作关系网络，也即公司的商业联盟范围。 |
| 财务表现 | 成本结构（Cost Structure） | 所使用的工具和方法的货币描述 |
| 财务表现 | 收入模型（Revenue Model） | 公司通过各种收入流来创造财富的途径 |
