一元函数中，某点导数 = 该点切线斜率；求导 = 求各点切线斜率的函数。

# 求导


求导的核心是：**用导数定义或求导法则，由 \(f(x)\) 求出 \(f'(x)\)**。实际做题时通常不用每次从极限定义算，而是“基本公式 + 求导法则”。


## 1. 导数定义

函数 \(y=f(x)\) 在 \(x\) 处的导数为：

\[
f'(x)=\lim_{\Delta x\to 0}\frac{f(x+\Delta x)-f(x)}{\Delta x}
\]

它表示函数在该点的瞬时变化率，几何上是切线斜率。

例：

\[
f(x)=x^2
\]

\[
f'(x)=\lim_{\Delta x\to 0}
\frac{(x+\Delta x)^2-x^2}{\Delta x}
=\lim_{\Delta x\to 0}\frac{2x\Delta x+(\Delta x)^2}{\Delta x}
=2x
\]

---

## 2. 先背基本导数公式

常见基本公式：

\[
(C)'=0
\]

\[
(x^n)'=nx^{n-1}
\]

\[
(e^x)'=e^x
\]

\[
(a^x)'=a^x\ln a
\]

\[
(\ln x)'=\frac1x
\]

\[
(\sin x)'=\cos x
\]

\[
(\cos x)'=-\sin x
\]

\[
(\tan x)'=\sec^2 x=\frac1{\cos^2 x}
\]

\[
(\arcsin x)'=\frac1{\sqrt{1-x^2}}
\]

\[
(\arctan x)'=\frac1{1+x^2}
\]

这些是基础，必须熟。

---

## 3. 掌握求导法则

### 和差法则

\[
(u\pm v)'=u'\pm v'
\]

### 常数倍

\[
(Cu)'=Cu'
\]

### 乘积法则

\[
(uv)'=u'v+uv'
\]

### 商法则

\[
\left(\frac uv\right)'=\frac{u'v-uv'}{v^2}
\]

### 链式法则：复合函数求导

若

\[
y=f(g(x))
\]

则

\[
y'=f'(g(x))\cdot g'(x)
\]

也就是“外层导数 × 内层导数”。

例：

\[
y=(3x+1)^5
\]

外层是 \(u^5\)，内层是 \(u=3x+1\)：

\[
y'=5(3x+1)^4\cdot 3
=15(3x+1)^4
\]

---

## 4. 求导的一般步骤

拿到一个函数，按这个顺序：

1. **看结构**：是加减、乘除，还是复合函数？
2. **拆外层和内层**：复合函数用链式法则。
3. **套基本公式**。
4. **化简**。
5. **检查定义域**：导数可能在某些点不存在。

---

## 5. 例子

### 例1

\[
y=3x^4-2x+5
\]

逐项求导：

\[
y'=12x^3-2
\]

### 例2

\[
y=x^2\sin x
\]

用乘积法则：

\[
y'=(x^2)'\sin x+x^2(\sin x)'
=2x\sin x+x^2\cos x
\]

### 例3

\[
y=\frac{\ln x}{x}
\]

用商法则：

\[
y'=\frac{(\ln x)'x-\ln x\cdot x'}{x^2}
=\frac{\frac1x\cdot x-\ln x}{x^2}
=\frac{1-\ln x}{x^2}
\]

### 例4

\[
y=e^{x^2}
\]

用链式法则：

\[
y'=e^{x^2}\cdot (x^2)'=2xe^{x^2}
\]

---

## 6. 更复杂的情况

后面还会学：

- **隐函数求导**：如 \(x^2+y^2=1\)，两边对 \(x\) 求导；
- **参数方程求导**：\(\frac{dy}{dx}=\frac{dy/dt}{dx/dt}\)；
- **对数求导法**：适合 \(y=x^x\)、多个因子乘除；
- **高阶导数**：对导数再求导，如 \(f''(x)\)；
- **偏导数**：多元函数对某一变量求导。

---

总结成一句话：

> **求导 = 熟记基本公式 + 识别函数结构 + 正确使用和差、乘积、商、链式法则 + 化简。**

初学阶段重点练三类：  
**多项式求导、乘积/商求导、复合函数链式求导。**

双向注意力 = 注意力在方向/交互上是双向的；不是把注意力头分成两个。

方向上的双向
指每个位置能同时看左边和右边的上下文。

BERT 的 self-attention 是双向的：每个 token 可以看到整句前后文。

GPT 的 causal self-attention 是单向的：只能看左边/前文。
这里的“双向”是信息可见方向，不是把注意力头拆成两个。

# 什么是 Agent？
Agent = LLM (大脑) + Planning (规划) + Tool use (执行) + Memory (记忆)。
学习 Agent 需要思维转变： 从<code>对话框问答</code>进化为<code>目标驱动的任务执行</code>。

---

# AI Agent 整体架构

| 组件 | 主要职责 |
|---|---|
| 感知（Perception） | 接收用户输入、环境信息和工具返回结果。 |
| 模型（LLM） | 理解任务、分析信息并决定下一步操作。 |
| 工具（Tools） | 执行搜索、文件操作、代码运行和 API 调用等任务。 |
| 记忆（Memory） | 保存对话上下文、任务状态和需要长期使用的信息。 |
| 规划（Planning） | 拆解复杂任务，确定执行步骤，并根据结果调整计划。 |
