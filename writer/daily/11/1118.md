# 常见的推理与规划方法
在 Agent 开发中，经常会看到 CoT、ReAct、ToT、Reflection 等概念。

这些方法关注的重点不同，有些用于组织模型推理，有些用于结合工具执行，还有些用于检查和修正结果。

| 方法 | 基本思路 | 适用场景 |
|---|---|---|
| CoT | Chain-of-Thought，将复杂问题分解为中间推理步骤 | 数学、逻辑和复杂问题分析 |
| ReAct | 结合推理与工具操作，根据执行结果继续决策 | 搜索、工具调用、多步骤任务 |
| ToT | Tree of Thoughts，探索和评估多个候选推理路径 | 复杂问题求解、方案探索 |
| Reflection | 根据反馈检查并修正已有结果 | 代码修改、内容检查、任务优化 |

# AI 工程演进路线（Evolution）

| 阶段 | 关注点 | 关键能力 |
|---|---|---|
| Prompt Engineering | 怎么问 | 提示设计 |
| Context Engineering | 给什么信息 | 上下文组织 |
| Harness Engineering | 怎么组织能力 | 工具编排 |
| Loop Engineering | 怎么持续创造结果 | 自动执行与反馈 |

# AI Agent 的基本组成
AI Agent 的关键在于：**模型负责决策，工具负责执行，程序根据执行反馈持续推进任务。**

| 组成部分 | 主要作用 |
|---|---|
| 模型（LLM） | 理解任务、分析上下文，决定下一步操作。 |
| 工具（Tools） | 执行文件操作、搜索、计算和 API 调用。 |
| 状态与记忆（State / Memory） | 记录任务进度、对话历史和工具执行结果。 |
| 执行控制（Agent Runtime） | 调度工具、处理错误、控制循环和终止任务。 |
