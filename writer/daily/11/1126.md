# 流行三法则
- 个别人物（Law of the Few）法則
在这些特别人物中有人意识到了时尚趋向，通过自己的社交、自己的活力、热情和个人魅力把“暇步士”传染给大家。

- 附着力因素（Stickiness Factor）法則
有一些特别的方式能够使一条具有传染性的信息被人记住。

- 环境威力（Power of Context）法則

每年冬天，

其核心原理在病毒学中被称为 “抗原漂移”（Antigenic Drift）。

改变其表面抗原结构，从而逃避人群已有免疫力的过程。

# 白皮书、蓝皮书、红皮书的区别？

| 类型 | 核心发布主体 | 核心属性与功能 | 典型内容/例子 |
| :--- | :--- | :--- | :--- |
| **白皮书** | **政府 / 官方机构** | **官方立场宣示**，权威性最高 | 国防白皮书、人权状况白皮书 |
| **蓝皮书** | **学术界 / 智库（第三方）** | **学术研究与智库建议**，客观分析 | 经济形势分析、区域发展报告（如社科院蓝皮书） |
| **红皮书** | 依语境而定（官方/国际组织/其他） | **含义多样**：官方文书、**危机警示**、特定名录等 | 濒危物种红皮书、西班牙政府文件、“红宝书” |

# 浏览器内核

浏览器内核（通常指渲染引擎）决定了网页如何被解析和显示。目前活跃的内核屈指可数，形成了 **Blink、WebKit 和 Gecko 三足鼎立**的格局，而许多曾风靡一时的内核已停止维护或退居二线。

## 🌐 当前活跃的主流内核

| 内核 | 主要浏览器 / 产品 | 关键特点 |
| :--- | :--- | :--- |
| **Blink** | **Google Chrome**、**Microsoft Edge**、Opera、Brave、Vivaldi、三星浏览器、以及国内多数“极速模式”浏览器 | 由 Google 从 WebKit 分支而来，是目前**市场占有率绝对领先**的内核，生态最庞大，几乎等同于“Chromium 内核”。 |
| **WebKit** | **Apple Safari**、macOS/iOS 上的所有浏览器（因苹果政策限制）、部分 Linux 桌面浏览器（如 Epiphany） | 苹果主导的开源内核，在苹果生态内具有唯一性。跨平台性极佳，是 Blink 的“前身”。 |
| **Gecko** | **Mozilla Firefox**、Thunderbird 等 Mozilla 系产品，以及 Waterfox 等少数分支 | Mozilla 维护的开源内核，是**唯一能与 Blink 生态形成实质性竞争**的独立内核，尤其在隐私保护和扩展深度支持上有独特优势。 |

## 💡 补充：JavaScript 引擎
严格来说，“浏览器内核”还包含执行 JavaScript 的引擎，不过现在讨论时常主要指渲染引擎。几个关键的 JS 引擎包括：
*   **V8**：Google 开发，用于 Chrome 和 Node.js。
*   **SpiderMonkey**： Mozilla 开发，用于 Firefox。
*   **JavaScriptCore (Nitro)**： Apple 开发，用于 Safari。
