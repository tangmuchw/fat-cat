# 怎么分析对手内容

使用 SCS 模型，三个维度。

## 结构 （Structure）
- 标题是否为清晰的问题句
- 是否使用了分级标题
- 是否包含 FAQ（快速问答）、列表、流程图、表格等模块化内容

> 结构是 AI 处理内容的第一逻辑。

## 内容（Content）
- 内容深度是否足够？是否有实际方案、操作步骤？
- 是否提供行业观点、真实案例、引用数据？
- 客户看完是否真的得到帮助？

## 语义场（Semantics）
- 是否围绕某个主题持续输出内容？
- 是否有品牌、作者、组织等明确署名？
- 是否在多个平台保持一致表达？

> 重点建立答案体系。

# 如何超越已被选中者，比起写得更好？
1. 结构重构。使用模块化内容重新构建某个主题的内容。
2. 内容补强。让信息密度更高。在原有话题基础上，补充操作建议、失败示例、常见误区、场景案例。
3. 空白区切入（高手打法）。不做重复已有的内容，转而去回答没回答的那些问题。例如，从 “如何选XXX” 转到 “选完后，注意事项”。
