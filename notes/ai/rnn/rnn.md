# RNN 循环神经网络

循环神经网络（Recurrent Neural Network, 简称 RNN）是一类专门用于处理序列数据的人工神经网络模型，其核心特点在于具备“记忆”能力：通过隐藏状态（hidden state）在时间维度上传递信息，使模型能够捕捉上下文中的时序依赖关系。

与传统的前馈神经网络不同，RNN 采用循环连接结构，即当前时刻的输出不仅依赖于当前输入，还依赖于前一时刻的隐藏状态，从而能够对动态序列中的前后关联进行建模

---

## ∂ 符号

∂（中文名：偏）是数学中d的一种变体，主要用于表示偏导数，外文名包括del、partial（可读这个）、dabba等。该符号除表示多元函数偏导数外，还应用于雅可比矩阵的行列式、拓扑学集合边界、同调代数边缘算子等数学领域。

## 有三个致命问题

- 问题一：梯度消失，难以记忆长距离依赖
- 问题二：无法并行计算，训练慢
- 问题三：位置靠前的信息容易被"覆盖"

## 一、一句话：这段代码在干什么

给机器一个 4 个词的序列：

```text
词1 → 词2 → 词3 → 词4
```

每读一个词，机器就在内部更新一个“小本子”，记下到目前为止读过的内容。  
这个“小本子”就是 **隐藏状态**。代码最后打印的就是：

```text
读完词1后，小本子内容是什么
读完词2后，小本子内容是什么
读完词3后，小本子内容是什么
读完词4后，小本子内容是什么
```

输出：

```text
第 1 步隐藏状态: [0.0204, -0.0434, 0.0556]
第 2 步隐藏状态: [-0.0061, -0.0529, 0.0775]
第 3 步隐藏状态: [0.0641, -0.0409, 0.0655]
第 4 步隐藏状态: [0.0143, -0.0805, 0.0277]
```

每行有 **3 个数**，因为代码设了：

```python
hidden_size = 3
```

意思是：小本子每页写 3 个数。

## 二、先忘掉代码：RNN 在干嘛

你可以把 RNN 想成一个“读词记笔记”的人。

### 第 1 步：读词 1

他手里有一个空本子：

```text
h_prev = [0, 0, 0]
```

读到词 1，他根据 **词 1** 和 **空本子**，写下新内容：

```text
h1 = [0.0204, -0.0434, 0.0556]
```

### 第 2 步：读词 2

他不再用空本子，而是用 **上一步写好的本子 h1**。  
读到词 2，他根据 **词 2** 和 **h1**，更新本子：

```text
h2 = [-0.0061, -0.0529, 0.0775]
```

### 第 3 步：读词 3

用 **词 3** 和 **h2**，更新：

```text
h3 = [0.0641, -0.0409, 0.0655]
```

### 第 4 步：读词 4

用 **词 4** 和 **h3**，更新：

```text
h4 = [0.0143, -0.0805, 0.0277]
```

所以整个流程就是：

```text
空本子 h0
  │
  │ 读词1
  ▼
h1
  │
  │ 读词2
  ▼
h2
  │
  │ 读词3
  ▼
h3
  │
  │ 读词4
  ▼
h4
```

**每一步都用了上一步的本子。** 这就是 RNN 的“循环”。

## 四、`step` 到底在算什么

`step` 的输入：

```python
x       # 当前词，4 维向量
h_prev  # 上一步的本子，3 维向量
```

输出：

```python
h_new   # 新本子，3 维向量
```

公式：

```text
h_new = tanh( Wx·x + Wh·h_prev + b )
```

不要被矩阵吓到，拆开看，它就是在算 3 个数：

```text
h_new[0] = tanh( 输入贡献0 + 记忆贡献0 + b[0] )
h_new[1] = tanh( 输入贡献1 + 记忆贡献1 + b[1] )
h_new[2] = tanh( 输入贡献2 + 记忆贡献2 + b[2] )
```

其中：

```text
输入贡献 = 当前词 x 乘以权重 Wx
记忆贡献 = 上一步本子 h_prev 乘以权重 Wh
```

画成图：

```text
当前词 x ────────┐
                 ▼
               Wx·x ─────┐
                         ├──▶ 相加 ──▶ tanh ──▶ 新本子 h_new
上一步本子 h_prev ─▶ Wh·h ─┘
                         ▲
                         b
```

所以 `step` 只做一件事：

> **根据“当前词”和“上一步本子”，算出“新本子”。**

## 五、用具体数字走一遍 `step`

为了好看，我假设隐藏状态只有 **1 个数**（真实代码是 3 个，原理一样）。

假设：

```text
上一步本子 h_prev = 0.5
当前词贡献 Wx·x = 0.2
记忆贡献 Wh·h_prev = 0.3
偏置 b = 0.1
```

那么：

```text
h_new = tanh(0.2 + 0.3 + 0.1)
      = tanh(0.6)
      ≈ 0.537
```

图：

```text
当前词贡献 0.2 ──┐
记忆贡献   0.3 ──┼──▶ 0.6 ──▶ tanh ──▶ 0.537
偏置       0.1 ──┘
```

这就是 `step` 的全部。

真实代码只是把这件事做了 3 遍：

```text
第 1 个数：用 Wx 第 0 列、Wh 第 0 列、b[0]
第 2 个数：用 Wx 第 1 列、Wh 第 1 列、b[1]
第 3 个数：用 Wx 第 2 列、Wh 第 2 列、b[2]
```

所以输出是 3 个数。

## 六、`forward` 就是重复 `step`

代码：

```python
hidden_state = [0.0, 0.0, 0.0]   # 空本子

for x in sequence:
    hidden_state = self.step(x, hidden_state)
    states.append(hidden_state)
```

翻译成人话：

```text
本子 = [0, 0, 0]

对序列里的每个词：
    本子 = step(当前词, 本子)
    把本子记下来
```

画成图：

```text
h0 = [0,0,0]
   │
   │ step(词1, h0)
   ▼
h1
   │
   │ step(词2, h1)
   ▼
h2
   │
   │ step(词3, h2)
   ▼
h3
   │
   │ step(词4, h3)
   ▼
h4
```

关键就一行：

```python
hidden_state = self.step(x, hidden_state)
```

右边用的是 **旧本子**，左边得到 **新本子**，下一步继续用新本子。

## 七、回到输出：4 行 3 个数怎么来的

序列有 4 个词：

```python
sequence = [
    [1,0,0,0],  # 词1
    [0,1,0,0],  # 词2
    [0,0,1,0],  # 词3
    [0,0,0,1],  # 词4

```

所以 `forward` 循环 4 次，得到 4 个本子：

```text
h1 → 第 1 行
h2 → 第 2 行
h3 → 第 3 行
h4 → 第 4 行
```

每个本子有 3 个数，因为：

```python
hidden_size = 3
```

所以输出是 4 行 × 3 列。

## 八、那“隐藏单元”到底是什么

现在再看“隐藏单元”就简单了：

```text
隐藏状态 = 小本子
隐藏单元 = 小本子上的一个数
```

代码里：

```text
hidden_size = 3
```

意思是本子每页写 3 个数：

```text
h = [第1个数, 第2个数, 第3个数]
        │         │         │
        │         │         └── 隐藏单元 2
        │         └──────────── 隐藏单元 1
        └────────────────────── 隐藏单元 0
```

每个隐藏单元在 `step` 里独立算一次：

```text
隐藏单元 0：h_new[0] = tanh(...)
隐藏单元 1：h_new[1] = tanh(...)
隐藏单元 2：h_new[2] = tanh(...)
```

它们都看 **同一个当前词** 和 **同一个上一步本子**，但使用不同的权重，所以算出不同的数。

你可以把它想成：

```text
本子上有 3 个格子
每读一个词，3 个格子都根据“当前词 + 旧格子内容”重新写一遍
```

这 3 个格子就是 3 个隐藏单元。

每一步都输出一个 3 维本子，所以最后有 4 行，每行 3 个数。

## 十、最简总结

- **输入**：4 个词，每个词 4 维。
- **隐藏状态**：一个 3 维向量，相当于“读到这里为止的笔记”。
- **step**：读一个词，结合旧笔记，写新笔记。
- **forward**：把 step 重复 4 次。
- **输出**：4 个时刻的笔记，每个笔记 3 个数。
- **隐藏单元**：笔记上的一个数；3 个隐藏单元就是笔记有 3 个数。

“梯度”这个词在这里指的是：**损失函数对某个参数的导数**，它告诉训练算法“这个参数往哪个方向调、调多少，能让损失变小”。

但 RNN 里说“梯度消失”，指的往往不只是参数梯度，还包括**隐藏状态沿时间反向传播时的梯度**。这两者要分开看。

---

## 1. 最基础：梯度是什么

假设模型输出一个预测 \(\hat{y}\)，真实答案是 \(y\)，损失是：

\[
L = (\hat{y} - y)^2
\]

训练时想知道：**如果把参数 \(w\) 稍微改一点，\(L\) 会怎么变？**  
这个“变化率”就是梯度：

\[
\frac{\partial L}{\partial w}
\]

更新规则：

\[
w \leftarrow w - \eta \cdot \frac{\partial L}{\partial w}
\]

- 梯度为正 → 减小 \(w\) 能降低 \(L\)
- 梯度为负 → 增大 \(w\) 能降低 \(L\)
- 梯度接近 0 → 几乎不知道该往哪调，参数学不动

所以梯度就是**训练的指南针**。

---

## 2. 在这段 RNN 里，梯度指哪些量

你的代码里有这些参数：

```python
self.wx   # 输入权重
self.wh   # 循环权重
self.b    # 偏置
```

如果加上训练，就需要算：

```text
∂L/∂wx    输入权重的梯度
∂L/∂wh    循环权重的梯度
∂L/∂b     偏置的梯度
```

这些叫 **参数梯度**。

但 RNN 还有一层特殊的东西：隐藏状态 \(h_t\) 沿时间传递。  
所以还要算：

```text
∂L/∂h_t       损失对第 t 步隐藏状态的梯度
∂h_t/∂h_{t-1} 第 t 步隐藏状态对上一隐藏状态的梯度
```

这些叫 **隐藏状态梯度** 或 **时间维梯度**。

“RNN 梯度消失”主要说的是：**\(\partial L/\partial h_t\) 往早期时间步传的时候越来越小**，导致早期参数（尤其是 `Wh`）的梯度也接近 0。

---

## 3. 为什么 RNN 的梯度要沿时间连乘

普通全连接网络里，梯度从输出层往输入层传，经过几层就连乘几次。  
RNN 不一样：**同一个 `Wh` 被每个时间步重复使用**，所以梯度要沿时间轴连乘很多次。

以你的 4 步序列为例，假设损失 \(L\) 只来自最后一步 \(h_4\)。  
要更新 `Wh`，需要：

\[
\frac{\partial L}{\partial W_h}
=
\frac{\partial L}{\partial h_4}
\cdot
\frac{\partial h_4}{\partial W_h}
\]

而 \(h_4\) 依赖 \(h_3\)，\(h_3\) 依赖 \(h_2\)，\(h_2\) 依赖 \(h_1\)。  
展开后，\(\partial L/\partial W_h\) 里会出现：

\[
\frac{\partial h_4}{\partial h_3}
\cdot
\frac{\partial h_3}{\partial h_2}
\cdot
\frac{\partial h_2}{\partial h_1}
\]

每一项都是：

\[
\frac{\partial h_t}{\partial h_{t-1}}
=
\text{diag}(1 - \tanh^2(z_t)) \cdot W_h
\]

所以：

\[
\frac{\partial h_4}{\partial h_1}
=
\prod_{t=2}^{4}
\left[
\text{diag}(1 - \tanh^2(z_t)) \cdot W_h
\right]
\]

**这就是连乘。** 序列越长，乘的次数越多。

---

## 4. 画成图看“梯度往回流”

前向：

```text
x1 → h1 → h2 → h3 → h4 → L
```

反向：

```text
L → h4 → h3 → h2 → h1
```

每往回走一步，梯度都要乘一个因子：

```text
∂L/∂h4
   │ × ∂h4/∂h3
   ▼
∂L/∂h3
   │ × ∂h3/∂h2
   ▼
∂L/∂h2
   │ × ∂h2/∂h1
   ▼
∂L/∂h1
```

如果每步因子大约是 0.5：

```text
∂L/∂h4 = 1
∂L/∂h3 ≈ 0.5
∂L/∂h2 ≈ 0.25
∂L/∂h1 ≈ 0.125
```

走 20 步：

```text
0.5^20 ≈ 0.000001
```

这就是**梯度消失**：早期时间步收到的梯度几乎为 0，参数几乎不更新，模型学不到“早期输入影响后期输出”这种长距离依赖。

---

## 5. 用你的代码具体对应

你的 `step`：

```python
h_new[i] = math.tanh(wx_sum + wh_sum + self.b[i])
```

对 `h_prev[j]` 求导：

\[
\frac{\partial h_{\text{new},i}}{\partial h_{\text{prev},j}}
=
(1 - h_{\text{new},i}^2) \cdot W_h[j][i]
\]

代码里对应：

```python
(1 - h_new[i] ** 2) * self.wh[j][i]
```

所以每一步反向传播，梯度都要乘：

```text
(1 - h_new[i]^2)   ← tanh 的导数，≤ 1
self.wh[j][i]      ← Wh 的元素，通常绝对值 < 1
```

你的代码里：

```python
self.wh = [
    [rng.uniform(-0.1, 0.1) for _ in range(hidden_size)]
    for _ in range(hidden_size)
]
```

`wh` 元素在 `[-0.1, 0.1]` 之间，绝对值很小。  
所以每反向一步，梯度大约乘一个小于 1 的数，连乘几次就非常小。

---

## 6. “梯度消失”消失的是哪个梯度

要区分三个层次：

| 梯度 | 含义 | 消失会怎样 |
|---|---|---|
| \(\partial L/\partial W_x\) | 输入权重的梯度 | 输入层学得慢 |
| \(\partial L/\partial W_h\) | 循环权重的梯度 | 循环连接学得慢，记不住历史 |
| \(\partial L/\partial h_t\) | 损失对第 t 步隐藏状态的梯度 | 早期时间步“收不到错误信号” |

“RNN 梯度消失”通常指第三项往早期传时趋近 0，进而导致第一、二项里**涉及早期时间步的部分**也趋近 0。

直观说：

```text
最后一步说：“我错了，要改。”
错误信号往回传：
  传到 h4：信号强
  传到 h3：弱一点
  传到 h2：很弱
  传到 h1：几乎没了
```

所以 `h1` 附近的参数几乎收不到“你也有责任”的信号。

---

## 7. 注意：这段代码本身没有梯度

你的代码只有：

```python
forward()  # 前向传播
```

没有损失函数，没有 `backward()`，没有优化器。  
所以**运行时并不会真的计算梯度**。

“梯度消失”是在说：**如果给这个 RNN 加上训练，梯度会怎样**。  
你现在的代码展示的是前向结果；梯度是训练视角下的概念。

---

## 8. 一句话总结

> **梯度是损失对参数的导数，表示参数该怎么调才能让损失下降。在 RNN 里，因为 `Wh` 和 `tanh` 在每个时间步重复使用，梯度沿时间反向传播时要连乘很多次 `tanh'` 和 `Wh`；这些因子通常小于 1，连乘导致早期时间步的梯度指数衰减，这就是梯度消失。梯度消失使早期参数收不到有效训练信号，所以 RNN 难以学习长距离依赖。**

对应到你代码里的两个“罪魁祸首”：

```python
math.tanh(...)   # 导数 ≤ 1
self.wh          # 元素绝对值通常 < 1
```

它们每步都参与连乘，序列一长，梯度就没了。
